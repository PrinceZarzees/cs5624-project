# Experiment outputs

Everything here is generated by the Phase 2+ commands in the top-level
`README.md`. Large artifacts are ignored by Git; keep only small summaries if
you need to commit results.

Suggested layout:

```text
experiments/
  baseline_a/<split>/        predictions, scores, summary, trajectories
  baseline_b/<split>/
  optimizer/                 best_harness.json, history, candidates, checkpoints
  scaling/                   one run dir per harness/split + scaling_summary.*
  ablation/                  full run + one run per removed rule
  qwen3_4b_pilot/           first real Qwen3-4B baseline pilot
  qwen3_4b/                 full Qwen3-4B BF16 pipeline
  qwen3_4b_opt_a/           optimizer starting from baseline_a
  qwen3_4b_scaling_full/    full-size scaling run (14-rule v2)
  qwen3_4b_ablation_full/   full test_large rule ablation
  qwen3_4b_ablation_stress/ full test_stress rule ablation
  qwen3_4b_ablation_val/    full val rule ablation (H* selection)
  qwen3_4b_real_bench/      real GraphArena/GraphQA evaluation
  analysis_by_characteristics.md  accuracy by density/topology/task
  optimization_costs.md     optimizer token/time/cost accounting
  REVIEW_EXPERIMENTS.md     review-driven experiment designs
  REVIEW_RESULTS.md         review experiment results
  review_c_backend/         C/gcc tool backend pilot
  review_optimizers/        GEPA, RRSI, Meta-Harness, router pilots
  qwen3_4b_cpu/             Qwen3-4B Q4_K_M CPU fallback
  qwen2_5_7b_cpu_pilot/     Qwen2.5-7B Q4_K_M CPU pilot
  qwen2_5_7b_cpu/           full Qwen2.5-7B CPU fallback
  comparison_plots/         4B vs 7B CPU comparison
  plots/                     accuracy_vs_size.{png,pdf}, accuracy_by_task.{png,pdf}
  cache/responses.sqlite     optional shared model-response cache
```

Useful checks before a large run:

```bash
python -m graphharness.runner --list-harnesses
python -m graphharness.runner --harness baseline_a --split test_small \
  --limit-per-task 1 --out /tmp/gh-smoke
```

If a run is interrupted, rerun the same command. `runner.py` reuses rows from
`predictions.jsonl`; `scaling.py` delegates to it for every split.
